# Контроль выполнения задач (Todo App)

Контроль выполнения задач (Todo App)
Небольшое учебное приложение на React, которое позволяет создавать, редактировать и контролировать выполнение запланированных задач.

---

🚀 Функциональность

- Отображение списка задач по умолчанию (демо-данные)
- Добавление новой задачи через поле «Новая задача»:
  - кнопкой Добавить
  - клавишей Enter
- Добавление задачи с указанием даты дедлайна
- Редактирование текста задачи по двойному клику
- Отметка выполнения задачи с помощью checkbox и зачёркнутого текста
- Фильтрация задач:
  - Активные
  - Выполненные
  - Важные
  - Отложенные
- Сортировка задач:
  - По алфавиту
  - По статусу
  - По дедлайну
- Поиск задач по тексту
- Отображение количества невыполненных задач
- История действий пользователя (undo / redo)
  - сохранение состояния в течение сессии
  - восстановление задач после перезагрузки страницы
- Поддержка Drag & Drop для изменения порядка задач
- Использование React Hooks (useState, useEffect)

🧠 Как это работает
Проект построен на функциональном подходе и управлении состоянием.
Основные компоненты

- App
  - инициализирует приложение
  - рендерит основной компонент
- TodoApp
  - содержит основную бизнес-логику
  - управляет состоянием задач и историей изменений
    Основные функции
- addTask — добавляет новую задачу
- toggleTask — меняет статус выполнения задачи
- deleteTask — удаляет задачу
- editTask — редактирует текст задачи
- undo — отменяет последнее действие
- redo — повторяет отменённое действие
- фильтрация, сортировка и поиск задач
- логика Drag & Drop

---

Компонент TodoItem
Отвечает за отображение одной задачи и обработку пользовательских действий:

- обработка событий мыши и клавиатуры
- визуальное представление задачи
  Используемые функции:
- deadlineStatusLabel — определяет статус дедлайна
  (просрочено / сегодня / завтра / будущее)
- saveEdit — сохраняет отредактированный текст
- cancelEdit — отменяет редактирование
